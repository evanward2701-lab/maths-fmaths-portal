# 6. Big Picture Explanation

The official CCEA topic `FA21-FCALC` is **Further calculus**. Ordinary A-Level Mathematics teaches the main calculus tools; Further Mathematics asks you to use them more flexibly, more exactly, and often in longer algebraic chains. The CCEA-core topic is centred on advanced integration and connected differentiation techniques: improper integrals; partial fractions with quadratic factors; inverse trigonometric differentiation; trigonometric substitution; repeated integration by parts; and reduction formulae.

The uploaded FP1 Methods in Calculus evidence is organised as three mini-chapters: Leibnitz’s theorem for advanced differentiation of products, L’Hospital’s rule for advanced limits using differentiation, and Weierstrass substitution for advanced integration using `t`-formulae.

This lesson therefore has two layers:

- **Layer A: CCEA-core Further calculus spine**, containing the six official CCEA LO areas.
- **Layer B: Evidence-backed enrichment**, containing Leibnitz’s theorem, L’Hospital’s rule and Weierstrass substitution.

The important student skill is not only doing the algebra. It is knowing which mathematical spell belongs in the official spellbook and which one is a glittery appendix.

# 7. Key Definitions and Notation

Let `x` be a real variable and let `y=f(x)` be a differentiable function. The first derivative may be written as `f'(x)` or `dy/dx`; the second derivative as `f''(x)` or `d^2y/dx^2`; and the `n`th derivative as `f^(n)(x)` or `d^n y/dx^n`. The notation `f^(n)(x)` means the function has been differentiated `n` times. It does not mean `(f(x))^n`.

If `y=uv`, then `u` and `v` are functions of `x`. The ordinary product rule says

```math
\frac{dy}{dx}=u\frac{dv}{dx}+v\frac{du}{dx}.
```

Using prime notation:

```math
y'=u'v+uv'.
```

The binomial coefficient is

```math
\binom nk=\frac{n!}{k!(n-k)!}.
```

Useful values are

```math
\binom n0=1,\qquad \binom n1=n,\qquad \binom n2=\frac{n(n-1)}2,\qquad \binom n3=\frac{n(n-1)(n-2)}6.
```

An expression such as `0/0` is an indeterminate form. It does not mean the value is zero. Other indeterminate forms in the uploaded evidence include `±∞/±∞`, `0×∞`, `∞−∞`, and `1^∞`.

The Weierstrass substitution uses

```math
t=\tan\frac{x}{2}.
```

Then

```math
\sin x=\frac{2t}{1+t^2},\qquad \cos x=\frac{1-t^2}{1+t^2},\qquad \tan x=\frac{2t}{1-t^2},\qquad dx=\frac{2}{1+t^2}\,dt.
```

## 8.2 Bridge Note: product rule to repeated product rule

In ordinary A-Level Maths, we used the product rule once:

```math
y=uv,\qquad y'=u'v+uv'.
```

Apply the product rule repeatedly:

```math
y''=u''v+2u'v'+uv''.
```

Differentiate again:

```math
y'''=u'''v+3u''v'+3u'v''+uv'''.
```

Differentiate a fourth time:

```math
y''''=u''''v+4u'''v'+6u''v''+4u'v'''+uv''''.
```

The coefficient pattern is `1, 4, 6, 4, 1`: Pascal’s triangle wearing a calculus cloak.

## 8.3 Optional enrichment: Leibnitz’s theorem

**Boundary status:** Not confirmed as CCEA-core from supplied CCEA evidence. Teach this as optional enrichment unless an official CCEA source confirms it.

If `y=uv`, where `u` and `v` are functions of `x`, then the `n`th derivative of `y` is

```math
y^{(n)}=\sum_{k=0}^{n}\binom nk u^{(k)}v^{(n-k)}.
```

Equivalently:

```math
\frac{d^ny}{dx^n}=\sum_{k=0}^{n}\binom nk\frac{d^ku}{dx^k}\frac{d^{n-k}v}{dx^{n-k}}.
```

The derivative orders add to `n`:

```math
k+(n-k)=n.
```

For `n=4`:

```math
y^{(4)}=uv^{(4)}+4u'v'''+6u''v''+4u'''v'+u''''v.
```

Method recipe: choose `u` and `v`; decide the derivative order; write derivatives of `u` in one direction; write derivatives of `v` in the matching reverse direction; write the binomial coefficients; multiply each row; add the terms; simplify carefully.

## 8.4 Optional enrichment: L’Hospital’s rule

**Boundary status:** Not confirmed as CCEA-core from supplied CCEA evidence.

Suppose

```math
\lim_{x\to a}\frac{f(x)}{g(x)}
```

produces either `0/0` or `±∞/±∞`. Then, provided the required derivative limit exists,

```math
\lim_{x\to a}\frac{f(x)}{g(x)}=\lim_{x\to a}\frac{f'(x)}{g'(x)}.
```

This is not the quotient rule. The quotient rule differentiates a function; L’Hospital’s rule evaluates a limit.

For example:

```math
\lim_{x\to0}\frac{\sin x}{x}=\lim_{x\to0}\frac{\cos x}{1}=1.
```

Some limits require repeated use:

```math
\lim_{x\to0}\frac{1-\cos x}{x^2}=\lim_{x\to0}\frac{\sin x}{2x}=\lim_{x\to0}\frac{\cos x}{2}=\frac12.
```

Forms such as `∞−∞`, `0×∞` and `1^∞` must be rewritten first.

## 8.5 Optional enrichment / boundary-risk support: Weierstrass substitution

**Boundary status:** Boundary-risk enrichment. CCEA `FA21-FCALC-LO004` includes trigonometric substitutions, but the supplied wording does not explicitly name Weierstrass substitution.

When

```math
t=\tan\frac{x}{2},
```

then

```math
\sin x=\frac{2t}{1+t^2},\qquad \cos x=\frac{1-t^2}{1+t^2},\qquad \tan x=\frac{2t}{1-t^2},\qquad dx=\frac{2}{1+t^2}\,dt.
```

Derive the `dx` formula by writing

```math
x=2\arctan t
```

so

```math
\frac{dx}{dt}=\frac{2}{1+t^2},\qquad dx=\frac{2}{1+t^2}\,dt.
```

For definite integrals, bounds must change. If `x=0`, then `t=0`. If `x=π/2`, then `t=tan(π/4)=1`.

# 11. Worked Examples

## 11.1 Worked Example Status Notice

The worked examples below are taken from the uploaded FP1 Methods in Calculus evidence. They are mathematically useful and evidence-backed, but remain optional enrichment / boundary-risk content unless a CCEA source explicitly confirms that the named method is required.

## 11.2 Leibnitz: `y=e^x sin x`, find `d^4y/dx^4`

Let

```math
u=e^x,\qquad v=\sin x.
```

Then

```math
u=u'=u''=u'''=u''''=e^x.
```

Also

```math
v=\sin x,\quad v'=\cos x,\quad v''=-\sin x,\quad v'''=-\cos x,\quad v''''=\sin x.
```

For the fourth derivative, the binomial coefficients are `1, 4, 6, 4, 1`.

```math
\frac{d^4y}{dx^4}=e^x\sin x-4e^x\cos x-6e^x\sin x+4e^x\cos x+e^x\sin x.
```

Group terms:

```math
e^x\sin x-6e^x\sin x+e^x\sin x=-4e^x\sin x,
```

and

```math
-4e^x\cos x+4e^x\cos x=0.
```

Therefore

```math
\boxed{\frac{d^4y}{dx^4}=-4e^x\sin x}.
```

## 11.3 Leibnitz with hyperbolic functions: `y=x^3 cosh 2x`

Let

```math
u=x^3,\qquad v=\cosh 2x.
```

Then

```math
u=x^3,\quad u'=3x^2,\quad u''=6x,\quad u'''=6.
```

Also

```math
v=\cosh 2x,\quad v'=2\sinh 2x,\quad v''=4\cosh 2x,\quad v'''=8\sinh 2x.
```

For `n=3`, the coefficient row is `1,3,3,1`, so

```math
\frac{d^3y}{dx^3}=x^3(8\sinh 2x)+3(3x^2)(4\cosh 2x)+3(6x)(2\sinh 2x)+6\cosh 2x.
```

Hence

```math
\boxed{\frac{d^3y}{dx^3}=8x^3\sinh 2x+36x^2\cosh 2x+36x\sinh 2x+6\cosh 2x}.
```

## 11.4 General nth derivative: `y=x^2e^{-x}`

Let

```math
u=x^2,\qquad v=e^{-x}.
```

Then

```math
u=x^2,\quad u'=2x,\quad u''=2,\quad u'''=0.
```

Also

```math
v^{(n)}=(-1)^ne^{-x},\quad v^{(n-1)}=-(-1)^ne^{-x},\quad v^{(n-2)}=(-1)^ne^{-x}.
```

Only the first three Leibnitz terms survive:

```math
\frac{d^ny}{dx^n}=\binom n0x^2(-1)^ne^{-x}+\binom n1(2x)(-1)^{n-1}e^{-x}+\binom n2(2)(-1)^{n-2}e^{-x}.
```

Use

```math
\binom n0=1,\quad \binom n1=n,\quad \binom n2=\frac{n(n-1)}2.
```

Then

```math
\frac{d^ny}{dx^n}=x^2(-1)^ne^{-x}-2nx(-1)^ne^{-x}+n(n-1)(-1)^ne^{-x}.
```

Factor:

```math
\boxed{\frac{d^ny}{dx^n}=(-1)^ne^{-x}\left(x^2-2nx+n(n-1)\right)}.
```

## 11.5 General nth derivative: `y=x^3e^{kx}`

Let

```math
u=x^3,\qquad v=e^{kx}.
```

Then

```math
u=x^3,\quad u'=3x^2,\quad u''=6x,\quad u'''=6,\quad u''''=0.
```

For `v=e^{kx}`,

```math
v^{(n)}=k^ne^{kx}.
```

Therefore

```math
\frac{d^ny}{dx^n}=x^3k^ne^{kx}+3nx^2k^{n-1}e^{kx}+3n(n-1)xk^{n-2}e^{kx}+n(n-1)(n-2)k^{n-3}e^{kx}.
```

Factor `k^{n-3}e^{kx}`:

```math
\boxed{\frac{d^ny}{dx^n}=k^{n-3}e^{kx}\left(k^3x^3+3nk^2x^2+3n(n-1)kx+n(n-1)(n-2)\right)}.
```

## 11.6 L’Hospital examples

```math
\lim_{x\to0}\frac{\sin x}{x}=\lim_{x\to0}\frac{\cos x}{1}=1.
```

```math
\lim_{x\to0}\frac{1-\cos x}{x^2}=\lim_{x\to0}\frac{\sin x}{2x}=\lim_{x\to0}\frac{\cos x}{2}=\frac12.
```

For

```math
\lim_{x\to0}(\cosec x-\cot x),
```

rewrite first:

```math
\cosec x-\cot x=\frac1{\sin x}-\frac{\cos x}{\sin x}=\frac{1-\cos x}{\sin x}.
```

Then

```math
\lim_{x\to0}\frac{1-\cos x}{\sin x}=\lim_{x\to0}\frac{\sin x}{\cos x}=0.
```

## 11.7 Weierstrass examples

Given

```math
t=\tan\frac{x}{2},
```

then

```math
x=2\arctan t,
```

so

```math
\frac{dx}{dt}=\frac{2}{1+t^2},\qquad dx=\frac{2}{1+t^2}\,dt.
```

For

```math
I=\int_0^{\pi/2}\frac{5}{4+2\cos\theta}\,d\theta,
```

use `t=tan(theta/2)`. Bounds: `theta=0 -> t=0`; `theta=pi/2 -> t=1`. Also

```math
\cos\theta=\frac{1-t^2}{1+t^2},\qquad d\theta=\frac{2}{1+t^2}\,dt.
```

Then

```math
I=\int_0^1 \frac{5}{4+2\left(\frac{1-t^2}{1+t^2}\right)}\cdot \frac{2}{1+t^2}\,dt.
```

Simplify:

```math
4+2\left(\frac{1-t^2}{1+t^2}\right)=\frac{6+2t^2}{1+t^2}.
```

Therefore

```math
I=\int_0^1\frac{5}{t^2+3}\,dt=\left[\frac5{\sqrt3}\arctan\frac{t}{\sqrt3}\right]_0^1=\frac{5\pi}{6\sqrt3}.
```

Equivalently,

```math
\boxed{I=\frac{5\pi\sqrt3}{18}}.
```

# 12. Common Mistakes and Exam Traps

- Treating the uploaded FP1 chapter as automatic CCEA-core content.
- Reading `u^(k)` as `u^k` instead of the `k`th derivative.
- Forgetting the binomial coefficient in Leibnitz’s theorem.
- Pairing derivative orders incorrectly. For `n=4`, `u^(2)v^(3)` is wrong because `2+3=5`.
- Losing the hyperbolic pattern `cosh 2x`, `2sinh 2x`, `4cosh 2x`, `8sinh 2x`.
- Forgetting the alternating sign in `d^n/dx^n e^{-x}=(-1)^ne^{-x}`.
- Using L’Hospital’s rule without checking `0/0` or `±∞/±∞`.
- Confusing L’Hospital’s rule with the quotient rule.
- Applying L’Hospital’s rule twice without checking the second form.
- Using Weierstrass substitution but forgetting `dx=2/(1+t^2)dt`.
- Changing the integrand but leaving definite integral bounds in `x`.
- Dropping absolute values in logarithmic antiderivatives.


## Solution 4

Let `u=x^2`, `v=sin x`. Then `u=x^2`, `u'=2x`, `u''=2`, `u'''=u''''=0`; `v=sin x`, `v'=cos x`, `v''=-sin x`, `v'''=-cos x`, `v''''=sin x`. Therefore

```math
y^{(4)}=uv''''+4u'v'''+6u''v''=x^2\sin x-8x\cos x-12\sin x.
```

## Solution 5

For `y=x^2e^{2x}`:

```math
\frac{d^ny}{dx^n}=x^2 2^ne^{2x}+n(2x)2^{n-1}e^{2x}+\frac{n(n-1)}2(2)2^{n-2}e^{2x}.
```

Factor `2^{n-2}e^{2x}`:

```math
\boxed{\frac{d^ny}{dx^n}=2^{n-2}e^{2x}(4x^2+4nx+n(n-1))}.
```

## Solution 6

```math
\lim_{x\to0}\frac{\tan x}{x}=\lim_{x\to0}\frac{\sec^2x}{1}=1.
```

## Solution 7

```math
\lim_{x\to0}\frac{x-\sin x}{x^3}=\lim_{x\to0}\frac{1-\cos x}{3x^2}=\lim_{x\to0}\frac{\sin x}{6x}=\lim_{x\to0}\frac{\cos x}{6}=\frac16.
```

## Solution 8

Rewrite:

```math
\frac1x-\cot x=\frac{\sin x-x\cos x}{x\sin x}.
```

Apply L’Hospital’s rule:

```math
\lim_{x\to0}\frac{\sin x-x\cos x}{x\sin x}=\lim_{x\to0}\frac{x\sin x}{\sin x+x\cos x}.
```

Apply it again:

```math
\lim_{x\to0}\frac{\sin x+x\cos x}{2\cos x-x\sin x}=0.
```

## Solution 9

From `t=tan(x/2)`, write `x=2 arctan t`, so

```math
\frac{dx}{dt}=\frac2{1+t^2},\qquad dx=\frac2{1+t^2}\,dt.
```

## Solution 10

```math
1+\cos x=1+\frac{1-t^2}{1+t^2}=\frac2{1+t^2}.
```

So

```math
\frac1{1+\cos x}\,dx=\frac{1+t^2}{2}\cdot\frac2{1+t^2}\,dt=dt.
```

## Solution 11

When `x=0`, `t=tan 0=0`. When `x=pi/2`, `t=tan(pi/4)=1`. Therefore the new bounds are `0 <= t <= 1`.

# 15. Exam Technique Notes

Before using a named method, ask whether it is explicitly in the CCEA Further Maths specification evidence. In this lesson, improper integrals, partial fractions with quadratic factors, inverse trig differentiation, trig substitution, repeated integration by parts and reduction formulae are CCEA-core. Leibnitz’s theorem, L’Hospital’s rule and Weierstrass substitution are not confirmed from supplied LOs.

For Leibnitz enrichment, define `u` and `v`, state `n`, write a derivative table, write binomial coefficients, multiply row by row and simplify. For L’Hospital enrichment, state the form check before differentiating. For Weierstrass enrichment, always convert `sin x`, `cos x`, `tan x`, `dx` and bounds.

Keep exact values such as `1/2`, `pi/6`, `sqrt(3)` and `arctan(1/sqrt(3))`. Do not decimalise unless asked.
