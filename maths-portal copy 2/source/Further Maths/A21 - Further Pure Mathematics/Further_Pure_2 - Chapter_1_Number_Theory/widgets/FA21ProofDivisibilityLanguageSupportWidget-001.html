Divisibility Notation Translator

Convert ordinary factor language into formal divisor notation, then write the proof sentence using exact integer arithmetic.

Boundary note: This widget supports CCEA proof language. It practises a divides b, written a | b, and the exact meaning b = ka for some integer k. It does not teach wider Number Theory algorithms as CCEA core.

Use an integer. Negative divisors are allowed. Zero is not allowed as a divisor in this course definition.

Memory hook

a | b means b = ka, where k ∈ ℤ.

Read the symbol from left to right: a divides b. The number after the bar is the number you are trying to write as a multiple of the number before the bar.
