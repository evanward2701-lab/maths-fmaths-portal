# 4. Learning Objectives

## Core Further Maths objectives

By the end of this lesson, you should be able to:

1. Interpret a complex number \(z=x+iy\) as a point \((x,y)\) on an Argand diagram.
2. Interpret \(\lvert z-a\rvert\) as the distance between the variable point \(z\) and the fixed point \(a\).
3. Construct and interpret the locus \(\lvert z-a\rvert=r\) as a circle.
4. Construct and interpret the locus \(\lvert z-a\rvert=\lvert z-b\rvert\) as a perpendicular bisector.
5. Construct and interpret the locus \(\arg(z-a)=\theta\) as a half-line/ray from the fixed point \(a\), with the starting point excluded.
6. Interpret simple regions involving inequalities, for example \(\lvert z-a\rvert<r\), \(\lvert z-a\rvert\le r\), and angular inequalities involving \(\arg(z-a)\).
7. Decide whether a boundary is included or excluded from the symbols \(<,\le,>,\ge\).

## Bridge objectives

You should connect this lesson to ordinary A-Level Maths by being able to:

1. Recognise \((x-a)^2+(y-b)^2=r^2\) as a circle.
2. Use midpoints and perpendicularity to understand equal-distance loci.
3. Use radians and exact trig values to interpret arguments.
4. Complete the square when a Cartesian circle equation appears.
5. Translate between geometry language and algebraic complex-number notation.

## Exam technique objectives

You should be able to:

1. Sketch an Argand diagram with labelled real and imaginary axes.
2. Mark fixed points accurately.
3. Use open circles where a point is excluded.
4. Shade the correct side of a boundary by testing a point if needed.
5. Write final region descriptions using clear set notation or clear chained inequalities.
6. Avoid importing FP2-only transformation methods into a CCEA FAS1 answer unless the question explicitly provides that structure.

# 5. Explicit Prerequisite Recap

## GCSE foundations

You should already be comfortable with coordinates, distance between points, midpoints, perpendicular bisectors, circles, basic angle measurement, and the idea that a locus is a set of points satisfying a condition.

A useful ordinary-geometry sentence:

> A locus is not one moving particle. It is the whole collection of positions that obey a rule.

That sentence matters. In complex numbers, \(z\) is not just one number. In a locus problem, \(z\) represents every possible complex number satisfying the condition.

In ordinary A-Level Maths, this idea appeared as coordinate geometry: points, distances, circles, perpendicular bisectors and angles.  
In Further Maths, the same idea becomes an Argand diagram: the horizontal axis is the real part, the vertical axis is the imaginary part, and a complex equation describes a geometric locus.  
The key upgrade is that expressions such as \(\lvert z-a\rvert\) and \(\arg(z-a)\) carry geometry inside the notation.  
The danger is treating the symbols as decoration. They are a miniature map: distance, centre, angle and direction are all encoded.

# 6. Big Picture Explanation

Complex-number loci are where algebra turns into cartography.

In ordinary algebra, an equation usually asks
\[
\text{Which number solves this?}
\]

In a complex-number locus problem, the question becomes
\[
\text{Which points in the complex plane satisfy this geometric condition?}
\]

That is why the Argand diagram matters. It lets us see a complex number \(z=x+iy\) as the point \((x,y)\). Once \(z\) is a point, expressions involving \(z\) become geometric instructions.

For example
\[
\lvert z-a\rvert=r
\]
means that the distance from the variable point \(z\) to the fixed point \(a\) is always \(r\). That is exactly the definition of a circle.

Similarly
\[
\lvert z-a\rvert=\lvert z-b\rvert
\]
means that the variable point \(z\) is the same distance from \(a\) as it is from \(b\). That is a perpendicular bisector.

And
\[
\arg(z-a)=\theta
\]
means that from the fixed point \(a\), a ray is drawn making angle \(\theta\) with the positive real direction.

So this lesson is about translating between
\[
\text{complex notation}\quad \longleftrightarrow \quad \text{geometry on an Argand diagram}.
\]

# 7. Key Definitions and Notation

## Complex number

A complex number has the form
\[
z=x+iy,
\]
where \(x,y\in\mathbb{R}\) and \(i^2=-1\).

The real part is
\[
\operatorname{Re}(z)=x.
\]

The imaginary part is
\[
\operatorname{Im}(z)=y.
\]

On an Argand diagram, \(z=x+iy\) is represented by the point \((x,y)\).

## Modulus

The modulus of \(z=x+iy\) is
\[
\lvert z\rvert=\sqrt{x^2+y^2}.
\]

Geometrically, \(\lvert z\rvert\) is the distance from the origin to the point \(z\).

If \(a=\alpha+i\beta\), then
\[
z-a=(x+iy)-(\alpha+i\beta)=(x-\alpha)+i(y-\beta).
\]

Therefore
\[
\lvert z-a\rvert
=
\sqrt{(x-\alpha)^2+(y-\beta)^2}.
\]

Geometrically, \(\lvert z-a\rvert\) is the distance from the point \(z=(x,y)\) to the fixed point \(a=(\alpha,\beta)\).

## Argument

The argument of \(z\), written \(\arg(z)\), is the angle measured from the positive real axis to the line from the origin to \(z\).

For \(z-a\), the expression \(\arg(z-a)\) means:

> Move the angle’s starting point from the origin to the fixed point \(a\), then measure the direction from \(a\) to \(z\).

## Locus

A locus is a set of points satisfying a rule. In this topic, the rule is usually written using \(z\), for example
\[
\lvert z-a\rvert=3.
\]

This does not mean \(z\) is one point. It means every point \(z\) whose distance from \(a\) is \(3\).

## Region

A region is a set of points satisfying an inequality or a combination of inequalities.

For example
\[
\lvert z-a\rvert<3
\]
means the inside of the circle centred at \(a\) with radius \(3\), not including the boundary.

\[
\lvert z-a\rvert\le 3
\]
means the inside of the same circle, including the boundary.

# 8. Core Theory

## 8.1 The basic dictionary: complex notation to geometry

Let
\[
z=x+iy,\qquad a=\alpha+i\beta.
\]

Then
\[
z-a=(x+iy)-(\alpha+i\beta).
\]

Subtract real parts and imaginary parts separately:
\[
z-a=x-\alpha+iy-i\beta.
\]

Factor the imaginary unit in the imaginary part:
\[
z-a=(x-\alpha)+i(y-\beta).
\]

So
\[
\lvert z-a\rvert
=
\sqrt{(x-\alpha)^2+(y-\beta)^2}.
\]

This is the distance formula between \((x,y)\) and \((\alpha,\beta)\).

**Bridge Note:** In ordinary A-Level Maths, the distance between \((x,y)\) and \((\alpha,\beta)\) is
\[
\sqrt{(x-\alpha)^2+(y-\beta)^2}.
\]
Here, Further Maths packages the same distance inside the compact expression \(\lvert z-a\rvert\).

## 8.2 Standard locus 1: \(\lvert z-a\rvert=r\)

Consider
\[
\lvert z-a\rvert=r.
\]

Let
\[
z=x+iy,\qquad a=\alpha+i\beta.
\]

Then
\[
z-a=(x-\alpha)+i(y-\beta),
\]
so
\[
\lvert z-a\rvert=\sqrt{(x-\alpha)^2+(y-\beta)^2}.
\]

Therefore
\[
\sqrt{(x-\alpha)^2+(y-\beta)^2}=r.
\]

Square both sides:
\[
(x-\alpha)^2+(y-\beta)^2=r^2.
\]

This is a circle with centre \((\alpha,\beta)\) and radius \(r\).

Since \(a=\alpha+i\beta\), the centre can also be described as the complex number \(a\).

So
\[
\boxed{\lvert z-a\rvert=r}
\]
is a circle centred at \(a\), with radius \(r\).

### Key warning

If
\[
a=3-2i,
\]
then the centre is
\[
(3,-2),
\]
not \((-3,2)\).

For example
\[
\lvert z-(3-2i)\rvert=5
\]
can be written as
\[
\lvert z-3+2i\rvert=5.
\]

The fixed point is still \(3-2i\), and the circle centre is \((3,-2)\).

## 8.3 Standard locus 2: \(\lvert z-a\rvert=\lvert z-b\rvert\)

Consider
\[
\lvert z-a\rvert=\lvert z-b\rvert.
\]

This means the point \(z\) is the same distance from \(a\) as it is from \(b\). That is the definition of the perpendicular bisector of the line segment joining \(a\) and \(b\).

Let
\[
a=\alpha+i\beta,\qquad b=\gamma+i\delta,\qquad z=x+iy.
\]

Then
\[
\lvert z-a\rvert
=
\sqrt{(x-\alpha)^2+(y-\beta)^2}
\]
and
\[
\lvert z-b\rvert
=
\sqrt{(x-\gamma)^2+(y-\delta)^2}.
\]

The locus equation is
\[
\sqrt{(x-\alpha)^2+(y-\beta)^2}
=
\sqrt{(x-\gamma)^2+(y-\delta)^2}.
\]

Square both sides:
\[
(x-\alpha)^2+(y-\beta)^2
=
(x-\gamma)^2+(y-\delta)^2.
\]

After expanding and simplifying, the \(x^2\) and \(y^2\) terms cancel, leaving a straight-line equation. That straight line is the perpendicular bisector of the segment from \(a\) to \(b\).

**Bridge Note:** In ordinary coordinate geometry, the perpendicular bisector is the set of points equidistant from two fixed points. Here, \(\lvert z-a\rvert=\lvert z-b\rvert\) is the same idea wearing complex-number armour.

### Mini-derivation example

Let
\[
\lvert z-2\rvert=\lvert z-(6+4i)\rvert.
\]

The fixed points are
\[
2=2+0i \quad \Rightarrow \quad (2,0)
\]
and
\[
6+4i \quad \Rightarrow \quad (6,4).
\]

Let
\[
z=x+iy.
\]

Then
\[
z-2=(x-2)+iy
\]
so
\[
\lvert z-2\rvert=\sqrt{(x-2)^2+y^2}.
\]

Also
\[
z-(6+4i)=(x-6)+i(y-4)
\]
so
\[
\lvert z-(6+4i)\rvert=\sqrt{(x-6)^2+(y-4)^2}.
\]

Thus
\[
\sqrt{(x-2)^2+y^2}
=
\sqrt{(x-6)^2+(y-4)^2}.
\]

Square both sides:
\[
(x-2)^2+y^2=(x-6)^2+(y-4)^2.
\]

Expand:
\[
x^2-4x+4+y^2
=
x^2-12x+36+y^2-8y+16.
\]

Collect the right-hand side:
\[
x^2-4x+4+y^2
=
x^2+y^2-12x-8y+52.
\]

Subtract \(x^2+y^2\) from both sides:
\[
-4x+4=-12x-8y+52.
\]

Add \(12x+8y\) to both sides:
\[
8x+8y+4=52.
\]

Subtract \(4\):
\[
8x+8y=48.
\]

Divide by \(8\):
\[
x+y=6.
\]

So the locus is
\[
\boxed{x+y=6}.
\]

It is the perpendicular bisector of the line segment from \((2,0)\) to \((6,4)\).

## 8.4 Standard locus 3: \(\arg(z-a)=\theta\)

Consider
\[
\arg(z-a)=\theta.
\]

This means that from the fixed point \(a\), the variable point \(z\) lies in a direction making angle \(\theta\) with the positive real direction.

So the locus is a ray starting at \(a\), going in direction \(\theta\).

But the point \(a\) itself is not included. At \(z=a\),
\[
z-a=0.
\]
The argument of \(0\) is undefined. A single zero vector has no direction.

So the locus
\[
\arg(z-a)=\theta
\]
is drawn as a ray from \(a\), but with an open circle at \(a\).

**Bridge Note:** In ordinary trigonometry, an angle is measured from a starting line. Here, \(\arg(z-a)\) moves the angle’s vertex to \(a\). The positive real direction still supplies the reference direction.

### Example interpretation

Consider
\[
\arg(z-(2+i))=\frac{\pi}{4}.
\]

The fixed point is \(2+i\). On the Argand diagram, this is \((2,1)\).

The angle is
\[
\frac{\pi}{4}=45^\circ.
\]

So the locus is the ray starting at \((2,1)\), making a \(45^\circ\) angle anticlockwise from the positive real direction.

The point \((2,1)\) is excluded.

## 8.5 Simple regions using modulus inequalities

The equation
\[
\lvert z-a\rvert=r
\]
is the boundary circle.

The inequality
\[
\lvert z-a\rvert<r
\]
means points whose distance from \(a\) is less than \(r\). So it is the inside of the circle, excluding the boundary.

The inequality
\[
\lvert z-a\rvert\le r
\]
means points whose distance from \(a\) is less than or equal to \(r\). So it is the inside of the circle, including the boundary.

Similarly,
\[
\lvert z-a\rvert>r
\]
means outside the circle, excluding the boundary, and
\[
\lvert z-a\rvert\ge r
\]
means outside the circle, including the boundary.

| Symbol | Boundary included? | Diagram style |
|---|---:|---|
| \(<\) | No | dotted/removed boundary |
| \(>\) | No | dotted/removed boundary |
| \(\le\) | Yes | solid boundary |
| \(\ge\) | Yes | solid boundary |

## 8.6 Simple regions using argument inequalities

An equation such as
\[
\arg(z-a)=\theta
\]
gives a boundary ray.

An inequality such as
\[
0<\arg(z-a)<\frac{\pi}{4}
\]
describes the angular region between two rays from the fixed point \(a\).

For example
\[
0\le \arg(z-2)\le \frac{\pi}{2}
\]
means:

- the angle is measured from \((2,0)\);
- the lower boundary is the ray from \((2,0)\) along the positive real direction;
- the upper boundary is the ray from \((2,0)\) vertically upwards;
- the region is the sector between those two rays;
- both boundaries are included because the inequalities are \(\le\).

The point \(z=2\) itself is excluded if the argument is being used directly, because \(\arg(0)\) is undefined.

## 8.7 Intersections of regions

Sometimes a region has two conditions at once, for example
\[
\lvert z-3\rvert\le 3
\]
and
\[
-\frac{\pi}{4}\le \arg(z-2)\le \frac{\pi}{2}.
\]

The first condition says inside or on the circle centred at \(3\) with radius \(3\). The second says between two rays starting at \(2\), from angle \(-\frac{\pi}{4}\) to angle \(\frac{\pi}{2}\).

The required region is the overlap of both conditions:
\[
\left\{z\in\mathbb{C}:
\lvert z-3\rvert\le 3
\text{ and }
-\frac{\pi}{4}\le \arg(z-2)\le \frac{\pi}{2}
\right\}.
\]

The word **and** is important. It means both conditions must be true.

## 8.8 Algebraic conversion for a circle locus

You may be asked to show that a modulus equation is a circle. The standard method is:

1. Write \(z=x+iy\).
2. Substitute into the locus equation.
3. Use \(\lvert X+iY\rvert=\sqrt{X^2+Y^2}\).
4. Square both sides if needed.
5. Complete the square.
6. State the centre and radius.

### Example: converting \(\lvert z-(3+4i)\rvert=5\)

Start with
\[
\lvert z-(3+4i)\rvert=5.
\]

Let
\[
z=x+iy.
\]

Then
\[
z-(3+4i)=x+iy-3-4i.
\]

Group real and imaginary parts:
\[
z-(3+4i)=(x-3)+i(y-4).
\]

Take the modulus:
\[
\lvert z-(3+4i)\rvert
=
\sqrt{(x-3)^2+(y-4)^2}.
\]

So
\[
\sqrt{(x-3)^2+(y-4)^2}=5.
\]

Square both sides:
\[
(x-3)^2+(y-4)^2=25.
\]

This is a circle with centre \((3,4)\) and radius \(5\).

In complex-number language, the centre is \(3+4i\).

3. \(\arg(z-a)=\theta\): ray from \(a\), open circle at \(a\), angle \(\theta\) measured from the positive real direction.

# 11. Worked Examples

## Worked Example 1: Circle locus from modulus notation

### Evidence source

This is a CCEA-on-spec generated worked example based on `FAS1-CN-LO012`. It follows the same standard modulus-to-distance interpretation that the transcript recaps for \(\lvert z-z_1\rvert=r\), where the fixed point gives the centre and the constant gives the radius.

### On-spec status

Core CCEA FAS1.

### Ordinary Maths idea used

Circle equation:
\[
(x-a)^2+(y-b)^2=r^2.
\]

### Further Maths upgrade

Complex modulus notation:
\[
\lvert z-a\rvert=r.
\]

### Question

Sketch the locus
\[
\lvert z-(2+3i)\rvert=4.
\]
State its centre and radius.

### Step-by-step solution

Let
\[
z=x+iy.
\]

The fixed complex number is
\[
2+3i.
\]

This is the point
\[
(2,3)
\]
on the Argand diagram.

The expression
\[
\lvert z-(2+3i)\rvert
\]
means the distance from the variable point \(z\) to the fixed point \(2+3i\).

So
\[
\lvert z-(2+3i)\rvert=4
\]
means that the distance from \(z\) to \(2+3i\) is \(4\).

Therefore the locus is a circle with centre
\[
2+3i,
\]
or as coordinates
\[
(2,3),
\]
and radius
\[
4.
\]

To confirm algebraically:
\[
z-(2+3i)=x+iy-2-3i.
\]

Group real and imaginary parts:
\[
z-(2+3i)=(x-2)+i(y-3).
\]

Take the modulus:
\[
\lvert z-(2+3i)\rvert
=
\sqrt{(x-2)^2+(y-3)^2}.
\]

So
\[
\sqrt{(x-2)^2+(y-3)^2}=4.
\]

Square both sides:
\[
(x-2)^2+(y-3)^2=16.
\]

This confirms the circle.

### Final exam-style answer

\[
\boxed{(x-2)^2+(y-3)^2=16}
\]

Centre:
\[
\boxed{(2,3)}
\]

Radius:
\[
\boxed{4}
\]

### Teaching note

Do not write the centre as \((-2,-3)\). The centre is the complex number being subtracted from \(z\):
\[
z-(2+3i).
\]

## Worked Example 2: Perpendicular bisector from equal moduli

### Question

Find the Cartesian equation of the locus
\[
\lvert z-1\rvert=\lvert z-(5+2i)\rvert.
\]

### Step-by-step solution

Let
\[
z=x+iy.
\]

The first fixed point is
\[
1=1+0i,
\]
so it is plotted at \((1,0)\).

The second fixed point is \(5+2i\), so it is plotted at \((5,2)\).

The equation
\[
\lvert z-1\rvert=\lvert z-(5+2i)\rvert
\]
means \(z\) is the same distance from \((1,0)\) and \((5,2)\). Therefore the locus is the perpendicular bisector of the line segment joining these two points.

Now find its equation algebraically.

First:
\[
z-1=(x+iy)-1=(x-1)+iy.
\]

Therefore
\[
\lvert z-1\rvert=\sqrt{(x-1)^2+y^2}.
\]

Next:
\[
z-(5+2i)=x+iy-5-2i=(x-5)+i(y-2).
\]

Therefore
\[
\lvert z-(5+2i)\rvert
=
\sqrt{(x-5)^2+(y-2)^2}.
\]

The locus equation is
\[
\sqrt{(x-1)^2+y^2}
=
\sqrt{(x-5)^2+(y-2)^2}.
\]

Square both sides:
\[
(x-1)^2+y^2=(x-5)^2+(y-2)^2.
\]

Expand the left-hand side:
\[
(x-1)^2+y^2=x^2-2x+1+y^2.
\]

Expand the right-hand side:
\[
(x-5)^2+(y-2)^2
=
x^2-10x+25+y^2-4y+4.
\]

So
\[
x^2-2x+1+y^2
=
x^2-10x+25+y^2-4y+4.
\]

Combine constants on the right:
\[
x^2-2x+1+y^2
=
x^2+y^2-10x-4y+29.
\]

Subtract \(x^2+y^2\) from both sides:
\[
-2x+1=-10x-4y+29.
\]

Add \(10x+4y\) to both sides:
\[
8x+4y+1=29.
\]

Subtract \(1\):
\[
8x+4y=28.
\]

Divide by \(4\):
\[
2x+y=7.
\]

### Final exam-style answer

\[
\boxed{2x+y=7}
\]

## Worked Example 3: Argument ray

### Question

Sketch the locus
\[
\arg(z+1-2i)=\frac{\pi}{3}.
\]

### Step-by-step solution

Rewrite the expression in the form
\[
\arg(z-a)=\theta.
\]

We have
\[
z+1-2i=z-(-1+2i).
\]

So the fixed point is
\[
a=-1+2i.
\]

On the Argand diagram, this is
\[
(-1,2).
\]

The argument is
\[
\frac{\pi}{3}.
\]

So the locus is the ray starting at \((-1,2)\), making angle \(\frac{\pi}{3}\) anticlockwise from the positive real direction.

But the starting point is not included because if \(z=-1+2i\), then
\[
z-(-1+2i)=0,
\]
and
\[
\arg(0)
\]
is undefined.

### Final exam-style answer

The locus is the ray from \((-1,2)\) at angle
\[
\boxed{\frac{\pi}{3}}
\]
to the positive real direction, with an open circle at \((-1,2)\).

## Worked Example 4: Combined simple region

### Question

Describe the region
\[
S=\left\{z\in\mathbb{C}:
\lvert z-3\rvert\le 3
\text{ and }
-\frac{\pi}{4}\le \arg(z-2)\le \frac{\pi}{2}
\right\}.
\]

### Step-by-step solution

We have two conditions.

First condition:
\[
\lvert z-3\rvert\le 3.
\]

The fixed point is \(3=3+0i\), so the centre is \((3,0)\). The radius is \(3\). The inequality is \(\le\), so the boundary circle is included.

This gives the inside of or on the circle centred at \((3,0)\) with radius \(3\).

Second condition:
\[
-\frac{\pi}{4}\le \arg(z-2)\le \frac{\pi}{2}.
\]

The fixed point is \(2=2+0i\), so the angle vertex is \((2,0)\).

The lower boundary ray is
\[
\arg(z-2)=-\frac{\pi}{4}.
\]

That ray starts at \((2,0)\) and goes downwards at \(45^\circ\) below the positive real axis.

The upper boundary ray is
\[
\arg(z-2)=\frac{\pi}{2}.
\]

That ray starts at \((2,0)\) and goes vertically upwards.

Both inequalities are inclusive, so both boundary rays are included except for the vertex point itself, where the argument is undefined.

The required region is the overlap of the disk
\[
\lvert z-3\rvert\le3
\]
and the angular sector
\[
-\frac{\pi}{4}\le \arg(z-2)\le\frac{\pi}{2}.
\]

### Final exam-style answer

Shade the part of the closed disk centred at \((3,0)\) with radius \(3\) that lies between the rays from \((2,0)\) at angles
\[
-\frac{\pi}{4}
\quad\text{and}\quad
\frac{\pi}{2}.
\]

Write
\[
\boxed{
S=\left\{z\in\mathbb{C}:
\lvert z-3\rvert\le 3
\text{ and }
-\frac{\pi}{4}\le \arg(z-2)\le \frac{\pi}{2}
\right\}.
}
\]

# 12. Common Mistakes and Exam Traps

## 12.1 Sign trap in the centre

Mistake:
\[
\lvert z+2-3i\rvert=4
\]
has centre \((2,-3)\).

Correct:
\[
z+2-3i=z-(-2+3i),
\]
so the centre is
\[
\boxed{(-2,3)}.
\]

The safest method is to rewrite in the form
\[
\lvert z-a\rvert=r.
\]

Then the centre is \(a\).

## 12.2 Forgetting that \(\arg(0)\) is undefined

For
\[
\arg(z-a)=\theta,
\]
the point \(z=a\) is not included. Even if the ray visually starts at \(a\), draw an open circle at \(a\).

## 12.3 Confusing inside and outside of a modulus inequality

\[
\lvert z-a\rvert<r
\]
means inside the circle.

\[
\lvert z-a\rvert>r
\]
means outside the circle.

A quick test point can save the day. Use the centre \(a\) if it is allowed.

At \(z=a\),
\[
\lvert z-a\rvert=0.
\]

Since \(0<r\), the centre is inside \(\lvert z-a\rvert<r\).

## 12.4 Treating \(\le\) as if it were \(<\)

For a boundary
\[
\lvert z-a\rvert=3,
\]
the region
\[
\lvert z-a\rvert<3
\]
does not include the circle itself.

The region
\[
\lvert z-a\rvert\le3
\]
does include the circle itself.

## 12.5 Using degrees when the question uses radians

If the question says
\[
\arg(z-a)=\frac{\pi}{4},
\]
do not write \(45\) as the answer unless you explicitly mean \(45^\circ\) and the context allows degrees. Use \(\frac{\pi}{4}\), \(\frac{\pi}{2}\), and \(\pi\).

## 12.6 Losing the geometry after doing algebra

If you derive
\[
(x-2)^2+(y+1)^2=9,
\]
you must still interpret it: centre \((2,-1)\), radius \(3\).

## 12.7 Squaring errors in modulus algebra

When squaring
\[
2\sqrt{A},
\]
remember
\[
(2\sqrt{A})^2=4A.
\]

The transcript gives this warning in the FP2 extension section. This warning is useful even though the specific \(k\)-locus is boundary-risk for this CCEA lesson.

## 12.8 Importing off-spec transformation work

The uploaded evidence includes transformations from the \(z\)-plane to the \(w\)-plane. Those are not taught as core CCEA FAS1 material here.

For this lesson, stay focused on
\[
\lvert z-a\rvert=r,\qquad
\lvert z-a\rvert=\lvert z-b\rvert,\qquad
\arg(z-a)=\theta,
\]
and simple regions.

# 15. Exam Technique Notes

## 15.1 Start every diagram with labelled axes

Use horizontal axis \(\operatorname{Re}\) and vertical axis \(\operatorname{Im}\). Do not label them \(x\) and \(y\) unless you are explicitly converting to Cartesian form.

## 15.2 Rewrite before plotting

Before plotting
\[
\lvert z+3-2i\rvert=5,
\]
rewrite it as
\[
\lvert z-(-3+2i)\rvert=5.
\]
Then the centre is clearly \((-3,2)\).

## 15.3 Use open circles for argument starting points

For
\[
\arg(z-a)=\theta,
\]
draw the ray from \(a\), but mark \(a\) with an open circle because \(z=a\Rightarrow z-a=0\), and \(\arg(0)\) is undefined.

## 15.4 Decide boundary inclusion from the symbol

| Symbol | Include boundary? |
|---|---:|
| \(<\) | No |
| \(>\) | No |
| \(\le\) | Yes |
| \(\ge\) | Yes |
| \(=\) | Boundary only |

## 15.5 Test a point if unsure where to shade

For
\[
\lvert z-a\rvert<r,
\]
test \(z=a\):
\[
\lvert a-a\rvert=0.
\]
If \(0<r\), the centre is inside the region.

For a more complicated inequality, pick a simple point such as \(z=0\), provided it is not on the boundary.

## 15.6 Use exact values

Prefer
\[
\frac{\pi}{4},\quad \frac{\pi}{2},\quad \sqrt2,\quad 2\sqrt2
\]
over decimals unless the question asks for decimals.

## 15.7 Do not overcomplicate simple CCEA loci

If you see
\[
\lvert z-a\rvert=r,
\]
do not immediately expand unless asked for a Cartesian equation.

If you see
\[
\lvert z-a\rvert=\lvert z-b\rvert,
\]
do not try to complete the square. It is a perpendicular bisector.

If you see
\[
\arg(z-a)=\theta,
\]
do not turn it into a tangent equation unless needed. It is a ray.

# 19. Final Student Checklist

## Prerequisite confidence checklist

Before moving on, check that you can:

- [ ] Plot \(z=x+iy\) as \((x,y)\) on an Argand diagram.
- [ ] Identify the real part and imaginary part of a complex number.
- [ ] Use \(\lvert x+iy\rvert=\sqrt{x^2+y^2}\).
- [ ] Recognise \((x-a)^2+(y-b)^2=r^2\) as a circle.
- [ ] Use radians such as \(\frac{\pi}{4}\), \(\frac{\pi}{2}\), and \(\pi\).

## Further Maths method checklist

You should now be able to:

- [ ] Interpret \(\lvert z-a\rvert=r\) as a circle.
- [ ] State the centre and radius of a modulus circle.
- [ ] Interpret \(\lvert z-a\rvert=\lvert z-b\rvert\) as a perpendicular bisector.
- [ ] Convert an equal-modulus locus into a Cartesian line equation.
- [ ] Interpret \(\arg(z-a)=\theta\) as a ray.
- [ ] Explain why the starting point of an argument ray is excluded.
- [ ] Sketch simple regions involving modulus and argument inequalities.
- [ ] Combine conditions using “and” as an overlap.

## Exam technique checklist

In an exam answer, remember to:

- [ ] Label the real and imaginary axes.
- [ ] Mark fixed points clearly.
- [ ] Use open circles for excluded argument vertices.
- [ ] Use solid boundaries for \(\le\) and \(\ge\).
- [ ] Use dotted/excluded boundaries for \(<\) and \(>\).
- [ ] Keep exact values where possible.
- [ ] Interpret your final equation geometrically.
- [ ] Avoid using FP2-only transformation methods unless explicitly required.

## Bridge checklist

You should be able to explain:

- [ ] How \(\lvert z-a\rvert\) is the distance from \(z\) to \(a\).
- [ ] How a modulus circle matches an ordinary coordinate circle.
- [ ] How equal modulus matches a perpendicular bisector.
- [ ] How argument uses ordinary angle measurement, but from a shifted point.
- [ ] Why a complex-number locus is a set of points, not one point.

## Diagram understanding checklist

Look at any Argand diagram in this topic and ask:

- [ ] Where is the fixed point?
- [ ] Is the condition about distance or angle?
- [ ] Is the boundary included?
- [ ] Is the region inside, outside, above, below, or between?
- [ ] Are there any excluded endpoints?
- [ ] Does the diagram match the algebra?
