χ² Confidence Interval for σ²

Build an enrichment confidence interval for a population variance using upper-tail χ² table values.

Boundary note: this widget is off-spec enrichment. It is included to illuminate the distribution of sample variance, not to redefine CCEA requirements.
For confidence level 100(1 − α)%:
(n − 1)S² / χ²ν(α/2) < σ² < (n − 1)S² / χ²ν(1 − α/2), where ν = n − 1.
Enter values, then calculate. You provide table values because exam tables are part of the learning ritual.
