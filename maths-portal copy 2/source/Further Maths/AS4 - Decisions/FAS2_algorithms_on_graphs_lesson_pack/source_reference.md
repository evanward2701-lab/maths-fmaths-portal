## Core Evidence Boundary

The CCEA Further Mathematics specification boundary controls the lesson. The core topic is:

```text
FAS2-ALGGRAPH: Algorithms on graphs
```

The foundation learning outcome taught is:

```text
FAS2-ALGGRAPH-LO001
demonstrate understanding of the definition of an algorithm, including the term greedy algorithm
```

## Ordinary A-Level Maths Bridge Sources

Ordinary A-Level Mathematics sources were used only for bridge context: arithmetic, substitution, sequences, table organisation, inequalities, percentage error and definite integration in an optional trace-table example. They do not override Further Mathematics evidence.

## Cross-Board Source Notes

The uploaded D1 evidence appears broader than the CCEA FAS2-ALGGRAPH boundary. It is used only where it supports CCEA-confirmed algorithm literacy.

## Final Evidence Boundary Statement

This lesson pack is a CCEA FAS2 Further Mathematics foundation lesson for algorithm understanding. The uploaded D1 evidence is used only to support CCEA-confirmed algorithm concepts and not to broaden the CCEA topic boundary.
