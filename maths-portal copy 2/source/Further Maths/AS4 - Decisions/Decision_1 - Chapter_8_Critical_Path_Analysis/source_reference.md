Ordinary A-Level Mathematics evidence was used only to explain prior table-reading, graph interpretation, maximum/minimum choice logic, modelling assumptions, units and interpretation. It was not used as Further Mathematics authority.

## Cross-Board Source Notes

The uploaded CPA evidence is Decision 1 style material. It is included because the following content matches the CCEA FAS2 CPA boundary: precedence tables, activity-on-arc networks, dummy activities, event times, forward/backward passes, critical activities, float times and the critical path algorithm.

## Final Evidence Boundary Statement

This pack is a CCEA FAS2 Further Mathematics Critical Path Analysis lesson. Core teaching is restricted to FAS2 critical path analysis: precedence tables, activity networks, event times, float times and the algorithm for finding the critical path. Ordinary A-Level Mathematics content is bridge context only, and cross-board material is used only where it matches the CCEA boundary.
