## Evidence use notes

The CCEA Further Mathematics specification map is the controlling authority for the syllabus boundary. The relevant LO is:

\[
\boxed{\text{FA22-ALGGRAPH-LO003: Use the simplex algorithm and tableau to solve two-variable linear programming problems.}}
\]

The uploaded Decision 1 material was used only where it supports the two-variable simplex tableau method: slack variables, objective-row convention, pivot column, theta values, pivot row, pivot element, row operations and final-tableau interpretation.

The teacher transcript was used for conceptual explanation, including:

- simplex as movement from vertex to vertex;
- the need to start from a feasible solution;
- slack variables as unused capacity;
- the significance of zero slack on boundary lines;
- why the most negative objective-row entry is chosen;
- why theta values identify the first constraint reached;
- why tableau row operations represent structured elimination.
