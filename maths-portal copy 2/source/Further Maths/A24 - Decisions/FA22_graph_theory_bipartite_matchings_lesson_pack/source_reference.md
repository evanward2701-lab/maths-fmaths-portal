## Off-Spec Content Excluded

The following lesson-specific evidence content was excluded from the CCEA core lesson:

- Hungarian algorithm;
- row reduction and column reduction;
- covering zeros with horizontal and vertical lines;
- finding the smallest uncovered element `e`;
- augmenting a matrix by `e`;
- dummy row or dummy column entries;
- maximum profit conversion by subtracting each entry from the largest value;
- incomplete data handled by artificial large values;
- 0-1 allocation linear programming using variables `x_ij`.
