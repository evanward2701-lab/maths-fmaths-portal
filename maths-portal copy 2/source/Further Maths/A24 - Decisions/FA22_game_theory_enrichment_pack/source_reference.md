## Off-Spec Content Excluded from Core

Game Theory, prisoner’s dilemma, zero-sum pay-off matrices, stable solution theorem, saddle points, dominance reduction, mixed strategies, graphical method and Game Theory linear programming are not presented as core CCEA Further Mathematics content. They are enrichment only.

## Final Evidence Boundary Statement

This pack is mathematically useful enrichment. It must not be placed in the compulsory CCEA GCE Further Mathematics revision sequence unless new official CCEA evidence confirms Game Theory as examinable content.
