Vector model

With r₀=(0,h), u=(uᵢ,uⱼ) and a=(0,-g), the position vector is r=r₀+ut+½at².

Position components

The widget uses x=uᵢt and y=h+uⱼt-½gt². Impact occurs when y=0.

Velocity and speed

Velocity is v=(uᵢ,uⱼ-gt). Speed is |v|=√(vᵢ²+vⱼ²).

Exam note

Show the vector equation, substitute values, solve the vertical equation for impact time, then use the horizontal component.

Model assumptions: projectile as particle, constant downward gravity, no air resistance.
