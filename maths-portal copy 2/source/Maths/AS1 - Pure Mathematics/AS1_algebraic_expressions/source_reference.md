## Missing Evidence Log

| Missing item | Expected use | Impact on lesson | Action taken |
|---|---|---|---|
| Topic-specific README for this exact chapter | Exact per-chapter metadata | Low | Used CCEA specification map and project module map |
| CCEA past-paper questions for this exact lesson | CCEA-specific exam practice | Medium | Created CCEA-aligned practice from specification and lesson evidence |
| Full Pearson textbook exercise pages | Complete exercise reproduction | Medium | Referenced only where the Dr Frost PDF indicated exercise pages; did not reproduce unseen textbook content |
| Full searchable screenshot PDF text | Detailed visual extraction | Low | Used only visible screenshot context already available |
| Official CCEA specification extract pasted in chat | Direct official extract | Low | Used pre-loaded specification map |

## Off-Spec or Boundary-Risk Log

| Evidence item | Why it is risky | Decision |
|---|---|---|
| Difference of cubes formula | Evidence itself notes it is not expected at this A-Level point | Marked enrichment only |
| MAT/UKMT extension problems | Beyond normal CCEA AS1 lesson demand | Excluded from core |
| Edexcel-branded questions | Cross-board source | Used only when the underlying algebra matched CCEA AS1-AF |
| Factor theorem / remainder theorem | Official AS1-AF content but not taught in this evidence | Logged as a future lesson boundary |
| Simple algebraic division | Part of AS1-AF-LO010 but not fully developed in this chapter evidence | Logged as a syllabus gap for this chapter |

## Evidence Limitations

- The screenshot PDF was treated as visual support only because no parsed text was available.
- GCSE bridge content was not used as core lesson evidence.
- Mermaid and TikZ assets are supplied as supplementary assets.
- SVG and widget placeholders match the generated assets.

## Source Use Summary

The specification map controls the syllabus. The project module map controls structure and naming. The evidence checklist controls missing/off-spec logging. The Dr Frost PDF and transcript supply the mathematical teaching content. Screenshot evidence supports visual design only.
