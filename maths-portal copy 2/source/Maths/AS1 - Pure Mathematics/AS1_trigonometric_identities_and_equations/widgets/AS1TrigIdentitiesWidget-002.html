AS1 Trig Equation Interval Checker

Check all solutions for equations of the form sin(ax+b)=k, cos(ax+b)=k, or tan(ax+b)=k in a stated degree interval. Use it after doing the algebra by hand.

Supported input for k: decimals, fractions like 1/2, and simple surd forms like sqrt(2)/2.

Exam-method reminder:

This widget is a checker. In written work, show the interval transformation, use the principal value carefully, generate all periodic solutions, then apply the final algebraic step to each value.

sin(x) = 0.5, for 0° ≤ x ≤ 360°
