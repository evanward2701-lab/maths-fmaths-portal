## Purpose
Show how a 2D vector can be written in column form and in i, j notation.

```mermaid
flowchart TD
    A["Column vector"] --> B["(x, y) as a vertical vector"]
    B --> C["Top component: x-direction"]
    B --> D["Bottom component: y-direction"]
    E["Unit vector i"] --> F["i = (1, 0)"]
    G["Unit vector j"] --> H["j = (0, 1)"]
    I["Any 2D vector"] --> J["(x, y) = x i + y j"]
    K["Example"] --> L["(4, 3) = 4i + 3j"]
    M["Example"] --> N["5i - j = (5, -1)"]
```
