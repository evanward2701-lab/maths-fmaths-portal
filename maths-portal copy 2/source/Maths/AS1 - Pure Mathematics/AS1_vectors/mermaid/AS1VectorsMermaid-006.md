## Purpose
Show how to find the angle a vector makes with the positive x-axis using a component triangle.

```mermaid
flowchart TD
    A["Given vector a = (x, y)"] --> B["Sketch the vector first"]
    B --> C["Draw component triangle"]
    C --> D["Adjacent side = x"]
    C --> E["Opposite side = y"]
    D --> F["Use tan(theta) = opposite / adjacent"]
    E --> F
    F --> G["tan(theta) = y / x"]
    G --> H["theta = tan^-1(y / x)"]
    I["Check quadrant"] --> J["Use signs of x and y"]
    J --> K["State angle requested by question"]
```
