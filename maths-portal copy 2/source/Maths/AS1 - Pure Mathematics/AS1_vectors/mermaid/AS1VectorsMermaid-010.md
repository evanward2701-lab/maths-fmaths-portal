## Purpose
Show the modelling distinction between vector quantities and scalar quantities, especially velocity versus speed and displacement versus distance.

```mermaid
flowchart TD
    A["Vector quantity"] --> B["Has magnitude and direction"]
    A --> C["Examples: velocity, displacement"]
    D["Scalar quantity"] --> E["Has magnitude only"]
    D --> F["Examples: speed, distance"]
    C --> G["Velocity vector v = (3, 4) km/h"]
    G --> H["Speed = |v|"]
    H --> I["Speed = sqrt(3^2 + 4^2) = 5 km/h"]
    C --> J["Displacement vector d = (-5, 12) km"]
    J --> K["Distance from start = |d|"]
    K --> L["Distance = sqrt((-5)^2 + 12^2) = 13 km"]
    M["Exam trap"] --> N["Do not call a vector speed"]
    M --> O["Do not call a scalar velocity"]
```
