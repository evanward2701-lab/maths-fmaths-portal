Remainder Theorem Substitution Checker

For a linear divisor Ax+B, solve Ax+B=0, then substitute that value into f(x). The result is the remainder. If the result is 0, the divisor is a factor.

Polynomial f(x)=ax³+bx²+cx+d

Linear divisor Ax+B

CCEA AS1 focus: remainder theorem and factor theorem for linear divisors. This widget is a checker, not a replacement for showing written substitution in an exam.
