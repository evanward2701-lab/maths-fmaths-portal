## Evidence Use Notes

The transcript and reveal-block PDF were used to preserve the teaching sequence:

1. AS recap using Pascal's triangle.
2. Binomial coefficient pattern using factorials.
3. Rational powers, including negative and fractional powers.
4. Infinite expansions and convergence.
5. Validity conditions.
6. Expansions where the constant is not \(1\).
7. Approximation questions.
8. Combining expansions.
9. Partial fractions before binomial expansion.
10. Common mistakes and exam traps.

The screenshot PDF was not treated as a reliable text source because the parsed view did not provide usable text. It remains logged as visual evidence only.
