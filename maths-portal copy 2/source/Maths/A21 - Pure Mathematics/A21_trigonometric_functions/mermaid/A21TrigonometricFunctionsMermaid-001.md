**Related lesson section:** Core Theory → New reciprocal Pythagorean identities  
**Purpose:** Show how both new reciprocal identities are derived from $\sin^2\theta+\cos^2\theta=1$.

```mermaid
flowchart TD
    A["Known identity:<br/>sin²θ + cos²θ = 1"]
    A --> B["Route 1:<br/>Divide every term by cos²θ"]
    B --> C["sin²θ/cos²θ + cos²θ/cos²θ = 1/cos²θ"]
    C --> D["tan²θ + 1 = sec²θ"]
    D --> E["1 + tan²θ = sec²θ"]
    A --> F["Route 2:<br/>Divide every term by sin²θ"]
    F --> G["sin²θ/sin²θ + cos²θ/sin²θ = 1/sin²θ"]
    G --> H["1 + cot²θ = cosec²θ"]
    E --> I["Use in reciprocal trig equations and proofs"]
    H --> I
```
