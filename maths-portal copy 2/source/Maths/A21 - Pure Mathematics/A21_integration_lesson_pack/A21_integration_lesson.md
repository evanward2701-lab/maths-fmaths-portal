## Learning Objectives

By the end, you should be able to:

1. Use standard integration results fluently.
2. Integrate functions with linear inner expressions $ax+b$.
3. Simplify algebraic and trigonometric expressions before integrating.
4. Use trig identities for $\sin^2x$, $\cos^2x$, $\tan^2x$ and products such as $\sin A\cos A$.
5. Use the reverse chain rule using the “consider, differentiate, scale” approach.
6. Use substitution and integration by parts.
7. Integrate rational functions using partial fractions.
8. Use definite integrals for area, limit-of-a-sum and volumes of revolution.
9. Solve separable differential equations and interpret model limitations.

## Prerequisite Recap

You should already be secure with differentiation, the chain rule, the product rule, logarithm laws, trigonometric identities and algebraic manipulation. No GCSE source is used as lesson evidence.

Useful log laws:

\[
\ln A-\ln B=\ln\left(\frac AB\right),
\qquad
k\ln A=\ln(A^k).
\]

A legal split:

\[
\frac{x+1}{x}=\frac{x}{x}+\frac1x=1+\frac1x.
\]

A false split:

\[
\frac{x}{x+1}\neq \frac{x}{x}+\frac{x}{1}.
\]

## Big Picture

Integration is reverse differentiation, but A2 integration is a method-selection topic. Before calculating, ask:

- Is this a standard result?
- Is the inside linear, $ax+b$?
- Can it be simplified first?
- Is a trig identity hiding?
- Is one part the derivative of another?
- Is it a product, suggesting integration by parts?
- Is it a rational expression needing partial fractions?
- Is it a differential equation?

A good integration answer is not just algebra. It is a small expedition with signposts.

## Key Definitions and Notation

### Indefinite integral

If

\[
\frac{d}{dx}F(x)=f(x),
\]

then

\[
\int f(x)\,dx=F(x)+C.
\]

The constant $C$ is required because constants differentiate to zero.

### Definite integral

\[
\int_a^b f(x)\,dx
\]

is a signed area. For area between curves:

\[
\text{Area}=\int_a^b(\text{top curve}-\text{bottom curve})\,dx.
\]

### Modulus in logarithms

\[
\int \frac1x\,dx=\ln|x|+C.
\]

The modulus is used because $\ln x$ is not defined for negative $x$.

## Core Theory A: Standard Functions

For $n\neq -1$,

\[
\int x^n\,dx=\frac{x^{n+1}}{n+1}+C.
\]

The teacher method is: increase the power, then divide by the new power.

Example:

\[
\int x^{1/2}\,dx
=
\frac{x^{3/2}}{3/2}+C
=
\frac23x^{3/2}+C.
\]

The case $n=-1$ is separate:

\[
\int x^{-1}\,dx=\int\frac1x\,dx=\ln|x|+C.
\]

### Standard result table

| Integrand | Integral |
|---|---|
| $x^n,\ n\neq -1$ | $\dfrac{x^{n+1}}{n+1}+C$ |
| $e^x$ | $e^x+C$ |
| $\dfrac1x$ | $\ln|x|+C$ |
| $\cos x$ | $\sin x+C$ |
| $\sin x$ | $-\cos x+C$ |
| $\sec^2x$ | $\tan x+C$ |
| $\cosec^2x$ | $-\cot x+C$ |
| $\sec x\tan x$ | $\sec x+C$ |
| $\cosec x\cot x$ | $-\cosec x+C$ |

[VISUAL PLACEHOLDER: A21IntegrationSVG-002 | Source: Chapter 11 slides/transcript | Insert from svg/A21IntegrationSVG-002.svg | Purpose: Standard results table.]

### Worked example

\[
\int\left(2\cos x+\frac3x-\sqrt{x}\right)\,dx
=
\int\left(2\cos x+\frac3x-x^{1/2}\right)\,dx.
\]

Integrate term by term:

\[
\int2\cos x\,dx=2\sin x,
\]

\[
\int\frac3x\,dx=3\ln|x|,
\]

\[
\int x^{1/2}\,dx=\frac{x^{3/2}}{3/2}=\frac23x^{3/2}.
\]

Therefore

\[
\boxed{
\int\left(2\cos x+\frac3x-\sqrt{x}\right)\,dx
=
2\sin x+3\ln|x|-\frac23x^{3/2}+C.
}
\]

## Core Theory B: Integrating $f(ax+b)$

If the inside is linear, integrate normally and divide by the coefficient of $x$.

For example,

\[
\frac{d}{dx}\sin(3x+1)=3\cos(3x+1).
\]

So

\[
\int\cos(3x+1)\,dx=\frac13\sin(3x+1)+C.
\]

[VISUAL PLACEHOLDER: A21IntegrationSVG-003 | Source: transcript/slides | Insert from svg/A21IntegrationSVG-003.svg | Purpose: Explain division by the inner derivative.]

Examples:

\[
\int e^{3x}\,dx=\frac13e^{3x}+C.
\]

\[
\int\frac1{5x+2}\,dx=\frac15\ln|5x+2|+C.
\]

\[
\int2\sec^2(3x-2)\,dx=\frac23\tan(3x-2)+C.
\]

For a power of a linear bracket:

\[
\int(3x+4)^3\,dx
=
\frac1{4}\cdot\frac1{3}(3x+4)^4+C
=
\boxed{\frac1{12}(3x+4)^4+C.}
\]

Check:

\[
\frac{d}{dx}\left(\frac1{12}(3x+4)^4\right)
=
\frac1{12}\cdot4(3x+4)^3\cdot3
=
(3x+4)^3.
\]

This simple divide-by-$a$ rule does not work directly when the inside is not linear.

## Core Theory C: Simplify Before Integrating

A numerator may be split over a single denominator:

\[
\frac{2x+1}{x}=\frac{2x}{x}+\frac1x=2+\frac1x.
\]

But a denominator may not be split:

\[
\frac{x}{x+1}\neq\frac{x}{x}+\frac{x}{1}.
\]

### Unknown-limit example

Given

\[
\int_a^{3a}\frac{2x+1}{x}\,dx=\ln12,
\]

find $a$.

Split first:

\[
\frac{2x+1}{x}=2+\frac1x.
\]

Then

\[
\int_a^{3a}\left(2+\frac1x\right)\,dx
=
[2x+\ln|x|]_a^{3a}.
\]

Substitute:

\[
(6a+\ln|3a|)-(2a+\ln|a|)
=
4a+\ln|3a|-\ln|a|.
\]

Use the log law:

\[
\ln|3a|-\ln|a|=\ln\left|\frac{3a}{a}\right|=\ln3.
\]

So

\[
4a+\ln3=\ln12.
\]

Therefore

\[
4a=\ln12-\ln3=\ln4,
\]

and

\[
\boxed{a=\frac14\ln4.}
\]

### Reciprocal trig simplification

\[
\frac{\cos x}{\sin^2x}
=
\frac{\cos x}{\sin x}\cdot\frac1{\sin x}
=
\cot x\cosec x.
\]

So

\[
\int\frac{\cos x}{\sin^2x}\,dx
=
\int\cosec x\cot x\,dx
=
\boxed{-\cosec x+C.}
\]

## Core Theory D: Trigonometric Identities

Some trig expressions must be rewritten before integration.

[VISUAL PLACEHOLDER: A21IntegrationSVG-004 | Source: Chapter 11 trig identity slides | Insert from svg/A21IntegrationSVG-004.svg | Purpose: Identity bridge for $\sin^2x$, $\cos^2x$, $\tan^2x$.]

### $\sin^2x$

\[
\cos2x=1-2\sin^2x.
\]

Rearrange:

\[
2\sin^2x=1-\cos2x,
\qquad
\sin^2x=\frac12-\frac12\cos2x.
\]

Therefore

\[
\int\sin^2x\,dx
=
\int\left(\frac12-\frac12\cos2x\right)\,dx
=
\boxed{\frac12x-\frac14\sin2x+C.}
\]

Wrong shortcut warning:

\[
\frac{d}{dx}\left(\frac13\sin^3x\right)
=
\sin^2x\cos x,
\]

so $\frac13\sin^3x$ is not the integral of $\sin^2x$.

### $\cos^2x$

\[
\cos2x=2\cos^2x-1.
\]

So

\[
\cos^2x=\frac12+\frac12\cos2x.
\]

Therefore

\[
\int\cos^2x\,dx
=
\boxed{\frac12x+\frac14\sin2x+C.}
\]

### $\tan^2x$

\[
1+\tan^2x=\sec^2x,
\qquad
\tan^2x=\sec^2x-1.
\]

So

\[
\int\tan^2x\,dx
=
\int(\sec^2x-1)\,dx
=
\boxed{\tan x-x+C.}
\]

### Product $\sin A\cos A$

\[
\sin2A=2\sin A\cos A,
\qquad
\sin A\cos A=\frac12\sin2A.
\]

Example:

\[
\int\sin3x\cos3x\,dx
=
\int\frac12\sin6x\,dx
=
\boxed{-\frac1{12}\cos6x+C.}
\]

## Core Theory E: Reverse Chain Rule

Reverse chain rule is the “consider, differentiate, scale” method.

[VISUAL PLACEHOLDER: A21IntegrationSVG-005 | Source: transcript | Insert from svg/A21IntegrationSVG-005.svg | Purpose: Reverse chain rule workflow.]

### Power of a bracket

\[
\int x(x^2+5)^3\,dx.
\]

The inside is $x^2+5$ and

\[
\frac{d}{dx}(x^2+5)=2x.
\]

Consider

\[
(x^2+5)^4.
\]

Differentiate:

\[
\frac{d}{dx}(x^2+5)^4
=
4(x^2+5)^3\cdot2x
=
8x(x^2+5)^3.
\]

This is $8$ times too large, so scale by $\frac18$:

\[
\boxed{
\int x(x^2+5)^3\,dx=\frac18(x^2+5)^4+C.
}
\]

### Logarithmic reverse chain rule

\[
\int\frac{4x}{x^2+1}\,dx.
\]

The derivative of $x^2+1$ is $2x$, and $4x=2(2x)$. Thus

\[
\int\frac{4x}{x^2+1}\,dx
=
2\int\frac{2x}{x^2+1}\,dx
=
\boxed{2\ln(x^2+1)+C.}
\]

### Negative power reverse chain rule

\[
\int\frac{x}{(x^2+1)^2}\,dx
=
\int x(x^2+1)^{-2}\,dx.
\]

Consider

\[
(x^2+1)^{-1}.
\]

Differentiate:

\[
\frac{d}{dx}(x^2+1)^{-1}
=
-1(x^2+1)^{-2}\cdot2x
=
-2x(x^2+1)^{-2}.
\]

Scale by $-\frac12$:

\[
\boxed{
\int\frac{x}{(x^2+1)^2}\,dx
=
-\frac12(x^2+1)^{-1}+C
=
-\frac1{2(x^2+1)}+C.
}
\]

## Core Theory F: Substitution

Substitution changes the variable to make the integral simpler.

[VISUAL PLACEHOLDER: A21IntegrationSVG-006 | Source: CCEA A21-INT-LO004 + lesson evidence | Insert from svg/A21IntegrationSVG-006.svg | Purpose: Substitution workflow.]

If

\[
u=g(x),
\]

then

\[
\frac{du}{dx}=g'(x),
\qquad
du=g'(x)\,dx.
\]

Everything in the integral must be rewritten in terms of $u$.

### Example

\[
\int x\sqrt{2x+5}\,dx.
\]

Let

\[
u=2x+5.
\]

Then

\[
u-5=2x,
\qquad
x=\frac{u-5}{2}.
\]

Also

\[
\frac{du}{dx}=2,
\qquad
dx=\frac12\,du,
\qquad
\sqrt{2x+5}=u^{1/2}.
\]

Substitute:

\[
\int x\sqrt{2x+5}\,dx
=
\int\frac{u-5}{2}\cdot u^{1/2}\cdot\frac12\,du
=
\frac14\int(u-5)u^{1/2}\,du.
\]

Expand:

\[
(u-5)u^{1/2}=u^{3/2}-5u^{1/2}.
\]

Integrate:

\[
\frac14\int(u^{3/2}-5u^{1/2})\,du
=
\frac14\left(\frac25u^{5/2}-5\cdot\frac23u^{3/2}\right)+C.
\]

So

\[
=
\frac1{10}u^{5/2}-\frac56u^{3/2}+C.
\]

Substitute back:

\[
\boxed{
\int x\sqrt{2x+5}\,dx
=
\frac1{10}(2x+5)^{5/2}
-\frac56(2x+5)^{3/2}+C.
}
\]

For definite integrals, either change the limits into $u$-limits or substitute back before applying the original $x$-limits.

## Core Theory G: Integration by Parts

Integration by parts reverses the product rule.

[VISUAL PLACEHOLDER: A21IntegrationSVG-007 | Source: CCEA A21-INT-LO004 + lesson evidence | Insert from svg/A21IntegrationSVG-007.svg | Purpose: Product rule to integration by parts.]

Start with

\[
\frac{d}{dx}(uv)=u\frac{dv}{dx}+v\frac{du}{dx}.
\]

Integrate and rearrange:

\[
\boxed{
\int u\frac{dv}{dx}\,dx=uv-\int v\frac{du}{dx}\,dx.
}
\]

### Example: $\int x\cos x\,dx$

Choose

\[
u=x,
\qquad
\frac{du}{dx}=1,
\qquad
\frac{dv}{dx}=\cos x,
\qquad
v=\sin x.
\]

Then

\[
\int x\cos x\,dx
=
x\sin x-\int\sin x\,dx.
\]

Since

\[
\int\sin x\,dx=-\cos x,
\]

\[
\boxed{
\int x\cos x\,dx=x\sin x+\cos x+C.
}
\]

### Example: $\int\ln x\,dx$

Write

\[
\int\ln x\,dx=\int1\cdot\ln x\,dx.
\]

Choose

\[
u=\ln x,
\qquad
\frac{du}{dx}=\frac1x,
\qquad
\frac{dv}{dx}=1,
\qquad
v=x.
\]

Then

\[
\int\ln x\,dx
=
x\ln x-\int x\cdot\frac1x\,dx
=
x\ln x-\int1\,dx.
\]

So

\[
\boxed{
\int\ln x\,dx=x\ln x-x+C.
}
\]

## Core Theory H: Partial Fractions

Partial fractions split a rational expression into pieces that are easier to integrate.

Example:

\[
\int\frac{3x+5}{(x+1)(x+2)}\,dx.
\]

Decompose:

\[
\frac{3x+5}{(x+1)(x+2)}
=
\frac{A}{x+1}+\frac{B}{x+2}.
\]

Multiply by $(x+1)(x+2)$:

\[
3x+5=A(x+2)+B(x+1).
\]

Expand:

\[
3x+5=(A+B)x+(2A+B).
\]

Equate coefficients:

\[
A+B=3,
\qquad
2A+B=5.
\]

Subtract:

\[
A=2.
\]

Then

\[
B=1.
\]

So

\[
\frac{3x+5}{(x+1)(x+2)}
=
\frac2{x+1}+\frac1{x+2}.
\]

Integrate:

\[
\boxed{
\int\frac{3x+5}{(x+1)(x+2)}\,dx
=
2\ln|x+1|+\ln|x+2|+C.
}
\]

Repeated linear factors need separate terms:

\[
\frac{2x+3}{(x-5)(x+4)^2}
=
\frac{A}{x-5}+\frac{B}{x+4}+\frac{C}{(x+4)^2}.
\]

Only power $-1$ terms integrate to logarithms. For example:

\[
\int C(x+4)^{-2}\,dx=-C(x+4)^{-1}+C_0.
\]

## Core Theory I: Area Between Curves

[VISUAL PLACEHOLDER: A21IntegrationSVG-008 | Source: CCEA A21-INT-LO002 | Insert from svg/A21IntegrationSVG-008.svg | Purpose: Top-minus-bottom area.]

For curves $y_{\text{top}}$ and $y_{\text{bottom}}$:

\[
\boxed{
\text{Area}=\int_a^b(y_{\text{top}}-y_{\text{bottom}})\,dx.
}
\]

Example: area between $y=x$ and $y=x^2$.

Find intersections:

\[
x=x^2,
\qquad
x^2-x=0,
\qquad
x(x-1)=0.
\]

So $x=0$ or $x=1$.

On $0<x<1$, $x>x^2$, so

\[
\text{Area}=\int_0^1(x-x^2)\,dx.
\]

Integrate:

\[
\int(x-x^2)\,dx=\frac{x^2}{2}-\frac{x^3}{3}.
\]

Apply limits:

\[
\left[\frac{x^2}{2}-\frac{x^3}{3}\right]_0^1
=
\frac12-\frac13
=
\boxed{\frac16.}
\]

## Core Theory J: Integration as the Limit of a Sum

[VISUAL PLACEHOLDER: A21IntegrationSVG-009 | Source: CCEA A21-INT-LO003 | Insert from svg/A21IntegrationSVG-009.svg | Purpose: Riemann rectangles.]

Split $[a,b]$ into $n$ equal strips:

\[
h=\frac{b-a}{n}.
\]

Using right endpoints,

\[
x_r=a+rh.
\]

Then

\[
\boxed{
\int_a^b f(x)\,dx=
\lim_{n\to\infty}\sum_{r=1}^n f(a+rh)h.
}
\]

Example:

\[
\int_0^1x^2\,dx.
\]

Here

\[
h=\frac1n,
\qquad
x_r=\frac rn.
\]

So

\[
f(x_r)h=\left(\frac rn\right)^2\frac1n=\frac{r^2}{n^3}.
\]

Thus

\[
\sum_{r=1}^n\frac{r^2}{n^3}
=
\frac1{n^3}\sum_{r=1}^n r^2.
\]

Use

\[
\sum_{r=1}^n r^2=\frac{n(n+1)(2n+1)}6.
\]

Then

\[
\frac1{n^3}\cdot\frac{n(n+1)(2n+1)}6
=
\frac{2n^3+3n^2+n}{6n^3}
=
\frac13+\frac1{2n}+\frac1{6n^2}.
\]

Taking the limit:

\[
\lim_{n\to\infty}\left(\frac13+\frac1{2n}+\frac1{6n^2}\right)
=
\boxed{\frac13.}
\]

## Core Theory K: Separable Differential Equations

[VISUAL PLACEHOLDER: A21IntegrationSVG-010 | Source: CCEA A21-INT-LO006/LO007 | Insert from svg/A21IntegrationSVG-010.svg | Purpose: Separation and model interpretation.]

A separable differential equation can be rearranged so that one variable is on one side and the other variable is on the other side.

Example:

\[
\frac{dV}{dt}=-kV.
\]

Divide by $V$:

\[
\frac1V\frac{dV}{dt}=-k.
\]

Multiply by $dt$:

\[
\frac1V\,dV=-k\,dt.
\]

Integrate:

\[
\int\frac1V\,dV=\int-k\,dt.
\]

So

\[
\ln|V|=-kt+C.
\]

Exponentiate:

\[
|V|=e^Ce^{-kt}.
\]

Let $A=e^C$. For positive $V$,

\[
\boxed{V=Ae^{-kt}.}
\]

If $V(0)=V_0$,

\[
V_0=Ae^0=A,
\]

so

\[
\boxed{V=V_0e^{-kt}.}
\]

Interpretation and limitations:

- $k$ is assumed constant.
- The model assumes continuous change.
- The model may be valid only over a particular time interval.
- Real measurements may not follow the model exactly.

## Core Theory L: Volumes of Revolution About the $x$-Axis

[VISUAL PLACEHOLDER: A21IntegrationSVG-011 | Source: CCEA A21-INT-LO008 | Insert from svg/A21IntegrationSVG-011.svg | Purpose: Volume generated by rotation about the $x$-axis.]

If the area under $y=f(x)$ from $x=a$ to $x=b$ is rotated about the $x$-axis, the volume is

\[
\boxed{
V=\pi\int_a^b y^2\,dx.
}
\]

The square appears because each cross-section is a circle with radius $y$, so its area is $\pi y^2$.

Example: rotate $y=x^2$ from $x=0$ to $x=2$ about the $x$-axis.

\[
y^2=(x^2)^2=x^4.
\]

So

\[
V=\pi\int_0^2x^4\,dx
=
\pi\left[\frac{x^5}{5}\right]_0^2
=
\pi\left(\frac{2^5}{5}-0\right)
=
\boxed{\frac{32\pi}{5}.}
\]

Evidence limitation: this content is included because CCEA A21-INT-LO008 requires it, even though the uploaded Dr Frost/Pearson evidence treats volume of revolution differently.

## Guided Practice with Full Worked Solutions

### Question 1

Find

\[
\int\left(5e^x-\frac4x+3\sin x\right)\,dx.
\]

Solution:

\[
\int5e^x\,dx=5e^x,
\]

\[
\int-\frac4x\,dx=-4\ln|x|,
\]

\[
\int3\sin x\,dx=-3\cos x.
\]

So

\[
\boxed{5e^x-4\ln|x|-3\cos x+C.}
\]

### Question 2

\[
\int\frac1{2x-3}\,dx
=
\boxed{\frac12\ln|2x-3|+C.}
\]

### Question 3

\[

### Question 5

\[
\int6x(x^2+4)^5\,dx.
\]

Since $(x^2+4)'=2x$ and $6x=3(2x)$,

\[
\int6x(x^2+4)^5\,dx
=
3\int2x(x^2+4)^5\,dx.
\]

Increase the power:

\[
\int2x(x^2+4)^5\,dx=\frac16(x^2+4)^6.
\]

Therefore

\[
\boxed{\frac12(x^2+4)^6+C.}
\]

### Question 6

\[
\frac{d}{dx}e^{x^2}=2xe^{x^2}.
\]

So

\[
\boxed{\int xe^{x^2}\,dx=\frac12e^{x^2}+C.}
\]

### Question 7

\[
\int x\sin x\,dx.
\]

Choose

\[
u=x,\qquad \frac{dv}{dx}=\sin x.
\]

Then

\[
\frac{du}{dx}=1,
\qquad
v=-\cos x.
\]

So

\[
\int x\sin x\,dx
=
-x\cos x-\int(-\cos x)\,dx
=
-x\cos x+\sin x+C.
\]

\[
\boxed{-x\cos x+\sin x+C.}
\]

### Question 8

\[
\frac{5x+1}{(x+1)(x+2)}
=
\frac{A}{x+1}+\frac{B}{x+2}.
\]

Then

\[
5x+1=A(x+2)+B(x+1)
=
(A+B)x+(2A+B).
\]

So

\[
A+B=5,\qquad 2A+B=1.
\]

Subtract:

\[
A=-4.
\]

Then

\[
B=9.
\]

So

\[
\boxed{
\int\frac{5x+1}{(x+1)(x+2)}\,dx
=
-4\ln|x+1|+9\ln|x+2|+C.
}
\]

### Question 9

Area between $y=2x$ and $y=x^2$.

Intersections:

\[
2x=x^2,
\qquad
x^2-2x=0,
\qquad
x(x-2)=0.
\]

So $x=0$ or $x=2$.

Top curve on $[0,2]$ is $y=2x$.

\[
\text{Area}=\int_0^2(2x-x^2)\,dx.
\]

\[
\int(2x-x^2)\,dx=x^2-\frac{x^3}{3}.
\]

\[
\left[x^2-\frac{x^3}{3}\right]_0^2
=
4-\frac83
=
\boxed{\frac43.}
\]

### Question 10

Solve

\[
\frac{dy}{dx}=3xy,
\qquad
y(0)=2.
\]

Separate:

\[
\frac1y\,dy=3x\,dx.
\]

Integrate:

\[
\ln|y|=\frac32x^2+C.
\]

Exponentiate:

\[
y=Ae^{\frac32x^2}.
\]

Use $y(0)=2$:

\[
2=Ae^0=A.
\]

So

\[
\boxed{y=2e^{\frac32x^2}.}
\]

### Question 11

Rotate $y=3x$ from $x=0$ to $x=1$ about the $x$-axis.

\[
V=\pi\int_0^1y^2\,dx
=
\pi\int_0^1(3x)^2\,dx
=
9\pi\int_0^1x^2\,dx.
\]

\[
9\pi\left[\frac{x^3}{3}\right]_0^1
=
9\pi\cdot\frac13
=
\boxed{3\pi.}
\]

## Common Mistakes and Exam Traps

| Trap | Correct response |
|---|---|
| Forgetting $+C$ | Include $+C$ for indefinite integrals |
| Using the power rule on $x^{-1}$ | Use $\ln|x|+C$ |
| Missing modulus in log answers | Use $\ln|f(x)|$ unless the expression is always positive |
| Forgetting to divide by inner derivative | Check by differentiating |
| Treating $\sin^2x$ as a normal power | Use double-angle identities |
| Splitting a denominator | Only split sums in numerators over one denominator |
| Making every fraction into a log | Check whether it is $\frac{f'}{f}$ |
| Wrong $u$ in integration by parts | Choose the part that simplifies when differentiated |
| Mixing $x$-limits with $u$-integrands | Change limits or substitute back |
| Bottom minus top for area | Use top minus bottom |
| Forgetting square in volume | Use $V=\pi\int y^2\,dx$ |

---

## Exam Technique

Always check an indefinite integral by differentiating your answer.

Prefer exact answers:

\[
\frac14\ln4,\qquad \frac{\pi}{12},\qquad \frac{32\pi}{5}.
\]

A calculator may check a definite integral, but algebraic working is still required for method marks.

For differential equations in context, finish with interpretation and limitations.
