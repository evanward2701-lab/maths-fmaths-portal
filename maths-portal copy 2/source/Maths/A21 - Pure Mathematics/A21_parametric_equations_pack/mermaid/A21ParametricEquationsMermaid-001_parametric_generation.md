## Purpose
Show how a parameter generates both coordinates of a point on a curve.

```mermaid
flowchart TD
    A["Choose a parameter value t"] --> B["Calculate x = p(t)"]
    A --> C["Calculate y = q(t)"]
    B --> D["Form the point (x, y)"]
    C --> D
    D --> E["Plot the point on the coordinate plane"]
    E --> F["Repeat for many values of t"]
    F --> G["The traced points form the parametric curve"]
    H["Important idea"] --> I["t is hidden on the final graph"]
    I --> J["The visible point is (x, y), not (x, y, t)"]
```
