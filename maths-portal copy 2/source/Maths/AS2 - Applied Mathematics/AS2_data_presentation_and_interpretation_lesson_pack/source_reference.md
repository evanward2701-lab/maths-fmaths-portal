## Learning Outcomes Used

Core lesson coverage:

- AS2-DPI-LO001: interpret diagrams for single-variable data, including understanding that area in a histogram represents frequency and connections to probability distributions
- AS2-DPI-LO002: interpret measures of central tendency and variation, including standard deviation and variance
- AS2-DPI-LO003: calculate standard deviation and variance of a population or sample, including from summary statistics
- AS2-DPI-LO008: recognise and interpret possible outliers in data sets and statistical diagrams
- AS2-DPI-LO009: select or critique data presentation techniques in the context of a statistical problem
- AS2-DPI-LO010: clean data, including dealing with missing data, errors and outliers

Same topic but outside this chapter focus:

- AS2-DPI-LO004
- AS2-DPI-LO005
- AS2-DPI-LO006
- AS2-DPI-LO007

These are correlation, regression and PMCC outcomes, so they should be handled in a separate AS2-DPI lesson.

## Evidence Content Summary

### Box plots and outliers

Evidence used:

- box plot anatomy;
- minimum, lower quartile, median, upper quartile, maximum;
- IQR and range;
- interpretation of each 25% section;
- outlier rule using \(Q_1-1.5IQR\) and \(Q_3+1.5IQR\);
- outlier rule using mean \(\pm2\sigma\);
- anomaly and cleaning data distinction;
- drawing box plots with crosses for outliers;
- comparing box plots using location and spread in context.

### Cumulative frequency diagrams

Evidence used:

- cumulative frequency as a running total;
- plotting upper boundaries against cumulative frequency;
- joining points using straight line segments under the equal-distribution assumption;
- estimating \(Q_1\), median and \(Q_3\);
- estimating counts less than, greater than and between values.

### Histograms

Evidence used:

- histogram as a representation for continuous grouped data;
- frequency density as frequency divided by class width;
- A-Level correction that area is proportional to frequency;
- use of \(\text{area}=k\times\text{frequency}\);
- converting areas into frequencies;
- true class boundaries when gaps or rounding appear;
- drawn histogram bar width and height scaling;
- forming frequency polygons from midpoints;
- including zero-frequency classes in frequency polygons.
