Select a probability notation and watch the matching Venn region appear. This is for AS2 set notation, complements, unions and intersections.

Intersection

A ∩ B
This means “A and B”. Shade only the overlap, because both events must happen.
Exam spark: for independence, do not just look at the Venn shape. You must compare P(A ∩ B) with P(A)P(B).
AS2 boundary note: this widget practises set notation and combined-event language. It does not use the conditional probability formula.
